Repositório com exercícios e materiais do curso **Desenvolvimento Web Full Stack**, organizados por módulos progressivos cobrindo fundamentos de front-end até conceitos avançados.

## 📚 Estrutura do Curso

```
dev-web-full-stack/
└── full-stack/
    ├── m-1-3/       # Módulos 1-3: Fundamentos (HTML, CSS básico, JavaScript introdutório)
    ├── m-4/         # Módulo 4: CSS Avançado (Layout, Position, Flexbox, Grid, Responsividade)
    ├── m-5/         # Módulo 5: JavaScript Intermediário/ES6+
    └── m-6/         # Módulo 6: Projetos integradores / Frameworks
```

## 🎯 Módulos e Conteúdos

### **Módulos 1-3: Fundamentos** (`m-1-3/`)
- Estrutura HTML semântica
- CSS básico: seletores, box model, tipografia
- Introdução ao JavaScript: variáveis, funções, DOM básico
- Projeto: Página pessoal simples (`aula/index.html`, `sobre.html`)

### **Módulo 4: CSS Avançado** (`m-4/`)
| Exercício | Tópico |
|-----------|--------|
| 01-display | Propriedade `display` (block, inline, inline-block, none) |
| 02-overflow | Controle de overflow (visible, hidden, scroll, auto) |
| 03-alinhamento | Alinhamento de elementos (text-align, margin:auto, flexbox) |
| 04-position | Positioning (static, relative, absolute, fixed, sticky) |
| 00-extras | Extras: menus mobile, floats, posicionamento avançado, reset CSS |

### **Módulo 5: JavaScript Avançado** (`m-5/`)
- ES6+: arrow functions, destructuring, modules, async/await
- Manipulação avançada do DOM
- Eventos e formulários

### **Módulo 6: Projeto Integrador** (`m-6/`)
- Aplicação completa combinando HTML, CSS e JavaScript
- Estrutura de projeto real

## 🚀 Como Usar

### Visualização Local
```bash
# Clone o repositório
git clone https://github.com/paulorabelo/dev-web-full-stack.git

# Navegue até o módulo desejado
cd dev-web-full-stack/full-stack/m-4/01-display

# Abra o index.html no navegador (duplo clique ou arraste)
```

### Servidor Local (Recomendado para JS)
```bash
# Python 3
cd dev-web-full-stack
python -m http.server 8000
# Acesse http://localhost:8000

# Node.js
npx serve .

# VS Code: Extensão "Live Server"
```
