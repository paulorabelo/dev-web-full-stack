# Dev Web Full Stack

This repository contains materials and exercises for full-stack web development, organized into modules.

## Structure

- `full-stack/`: Main directory containing module-based exercises
  - `m-1-3/`: Modules 1-3 (foundations)
  - `m-4/`: Module 4
  - `m-5/`: Module 5
  - `m-6/`: Module 6

Each module directory may contain source code, assignments, and resources for that week/topic.

## Usage

Explore each module directory to find the relevant code and instructions.

## Technologies

Technologies vary per module but may include HTML, CSS, JavaScript, frontend frameworks, backend languages, and databases.

## Contributing

This repository is primarily for educational purposes. If you find issues or have suggestions, feel free to open an issue.
